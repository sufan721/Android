# 路线图

按"已经能用的 / 明确不做的 / 打算做的"分开写，避免把愿望清单当成承诺。

## 1. 已完成（v1.0.0）

- **账号**：手机号注册、验证码、登录、修改密码、找回密码
- **好友**：搜索、申请与同意、备注、黑名单、删除
- **通讯录**：拼音索引、二维码名片、扫一扫
- **群组**：建群、邀请、踢人、改群名、群内昵称、退群、解散
- **会话**：会话列表与未读角标、文本/图片/语音/视频/位置/表情/红包七种消息、长按菜单、会话设置
- **我**：资料编辑、我的位置、设置、关于
- **工程**：MVP 基类、Retrofit + Cookie 持久化、融云 IM 封装、LitePal 缓存、文档体系、CI 与依赖维护配置

## 2. 明确不做的

| 功能 | 原因 |
|---|---|
| 朋友圈 | 需要独立的服务端信息流，与 IM 服务不是一套，工作量超出演示范围 |
| 音视频通话 | 融云 RTC 需要单独开通并计费，且要处理摄像头/音频路由适配 |
| 支付与提现 | 只保留红包的消息形态，不做资金流 |
| 多端同步 | 依赖服务端的消息漫游能力，客户端无法单方面实现 |
| 换肤 / 深色模式 | 颜色写死在 `colors.xml`，改造面太大，收益低 |

## 3. 计划中的

### 3.1 技术债（优先级最高）

1. **修构建链**：当前 `gradle 9.9.2` + AGP 2.3.0 + `compile` 配置三者互不兼容，仓库已无法编译。目标是把 AGP 升到 7.x、`compile` 全量换 `implementation`、`buildFeatures` 显式声明，并锁定 JDK 17 编译
2. **迁移 AndroidX**：`support 25.3.1` 与 butterknife 10、qiniu 8 已经不兼容，迁移要连 `autolayout`、`statusbaruitl` 一起换掉
3. **降级依赖**：butterknife 10.2.3、qiniu 8.11.0、retrofit 3.0.0、okhttp 5.5.1 是 Dependabot 自动升上来的，与老工程不匹配，确认最终技术栈后重新锁版本
4. **修 CI**：`setup-android` 需要 JDK 17+，且 jcenter 下线导致依赖解析失败；改为"手动触发 + 只校验 YAML 与单元测试"，或干脆换成 `gradle/gradle-build-action` 的新写法
5. **补测试**：目前只有 4 个工具类的单元测试，Presenter 层完全没有覆盖

### 3.2 功能

| 功能 | 说明 | 依赖 |
|---|---|---|
| 消息通知 | 应用在后台时用通知栏提醒，点击进入对应会话 | 融云推送或自建长连接 |
| @提醒 | 群聊里 @ 某人，被 @ 的人收到高亮提示 | 自定义消息 + 群成员表 |
| 输入中状态 | 对方正在输入… | 融云输入状态接口 |
| 消息漫游 | 换设备后能拉到历史消息 | 服务端能力 |
| 群公告编辑 | 目前只读，群主不能改 | `group/rename` 同类接口 |
| 聊天记录搜索 | 按关键词搜本地消息 | 融云本地搜索 API |

### 3.3 体验

- 图片消息支持查看大图时左右滑动（现在只能单张）
- 会话列表支持置顶与免打扰
- 长文本消息折叠

## 4. 版本节奏

- `1.0.x`：只修 bug 与文档，不动构建链
- `1.1.0`：构建链与 AndroidX 迁移，功能不变（目标是"能编译、能安装、能跑通登录"）
- `1.2.0`：消息通知与 @提醒
