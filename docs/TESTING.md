# 测试与自测清单

## 1. 测试分层

| 层级 | 位置 | 工具 | 覆盖内容 |
|---|---|---|---|
| 单元测试 | `app/src/test/java` | JUnit 4.12 | 工具类纯逻辑 |
| 仪器测试 | `app/src/androidTest/java` | Espresso 2.2.2 | 启动与基础交互 |
| 手工自测 | 真机 | — | IM 收发、地图、支付等依赖外部服务的功能 |

已有单元测试（全部在 `com.lqr.wechat.util`）：

- `PinyinUtilsTest`：汉字转拼音、首字母提取
- `StringUtilsTest`：空值判断、字符串拼接与截断
- `TimeUtilsTest`：会话列表时间格式（今天 / 昨天 / 本周 / 更早）
- `RegularUtilsTest`：手机号、密码、昵称的正则校验

## 2. 运行方式

```bash
# 单元测试（不需要设备）
./gradlew test
# 报告：app/build/reports/tests/testDebugUnitTest/index.html

# 只跑某个类
./gradlew test --tests "com.lqr.wechat.util.TimeUtilsTest"

# 仪器测试（需要连接设备或模拟器）
./gradlew connectedAndroidTest
```

单元测试不依赖 Android 框架，凡是需要在 UI 层验证的逻辑，请下沉到 `util` 或 Presenter 里再测，不要为了测试去 mock `Context`。

## 3. 提交前自测（必做）

```bash
./gradlew test          # 单元测试
./gradlew assembleDebug # 能否编译
```

两者都通过才能开 PR。改到 `app/src/main/res` 下的资源时，额外确认 `assembleDebug` 没有资源冲突（三方 SDK 的 `rc_*`、`ssdk_*` 资源与本地同名时最容易冲突）。

## 4. 手工自测清单

### 4.1 登录注册

- [ ] 手机号格式错误时，登录按钮不可点或给出提示
- [ ] 密码长度不足时提示文案正确
- [ ] 注册成功后能自动登录并进入主界面
- [ ] 退出登录后重启应用回到登录页
- [ ] 融云连接失败时（改错 `RONG_CLOUD_APP_KEY`）有可读的提示，不是一直转圈

### 4.2 会话与消息

- [ ] 文本、图片、语音、视频、表情、位置、红包七种消息都能发出并收到
- [ ] 语音消息按住说话、松手发送、上滑取消三个动作都正常
- [ ] 长按消息能撤回、复制、删除
- [ ] 断网发送失败的消息有红色感叹号，点击可重发
- [ ] 未读数随消息增减正确，进入会话后清零
- [ ] 会话列表按最后一条消息时间倒序，时间格式正确

### 4.3 联系人与群组

- [ ] 联系人按拼音首字母分组，索引栏点击定位准确
- [ ] 搜索昵称、手机号能命中
- [ ] 添加好友发出申请，对方同意后双方列表都更新
- [ ] 建群后群成员数、群名正确，退群后会话消失
- [ ] 备注名修改后，会话列表与联系人列表同步显示备注

### 4.4 个人中心与设置

- [ ] 头像、昵称、签名修改后立即生效并同步到服务端
- [ ] 二维码名片能被扫一扫识别出用户
- [ ] 位置共享授权被拒绝时不崩溃，给出引导
- [ ] 清理缓存后图片重新加载正常

### 4.5 兼容性

- [ ] Android 6.0 及以上：相机、存储、定位、录音的运行时权限全部弹窗正常
- [ ] Android 7.0：拍照使用 FileProvider，不抛 `FileUriExposedException`
- [ ] arm64 与 armeabi-v7a 设备各测一台（`abiFilters` 只保留这两个）
- [ ] 720×1280 与其他分辨率下界面不溢出（项目使用 `autolayout`）

## 5. 已知限制

- 融云、腾讯地图、支付宝红包都需要真实 key 才能跑通，CI 环境只能验证编译与单元测试
- 仪器测试只覆盖启动流程，IM 相关流程依赖服务端，未做自动化
- 无网络环境下部分页面会一直显示加载中，属已知问题
